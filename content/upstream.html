What the ecosystem has that this machine does not

  • ECC's 68 subagents. The skills were cloned, the agents were not. This machine runs 21 resident personas from a different source (The Agency); ECC's are purpose-built for the same workflow the skills describe, so the two halves currently do not meet.
  • The Agent Skills spec and template from anthropics/skills. Closed 2026-09-04 Both arrived with the full re-clone; the local agent-skills-spec skill and its validate-skill.py now sit alongside the canonical scaffold.
  • financial-services' 11 MCP data connectors (Daloopa, Morningstar, FactSet, PitchBook and others). The skills are here; the connectors they assume are not configured, so several of the 57 will half-work on a real task.
  • knowledge-work's enterprise-search plugin — cross-tool search over email, chat and docs. Nothing local covers it.

One caution before pulling any of this was: volume is not the constraint here — reachability is. Adding 300 more vault skills to a search that already returned one winner out of four for dcf-model would make the library larger and no more useful.
